Tentang Saya.

Saya memiliki minat pada Software Engineering, Machine Learning, Data Mining, dan Internet of Things (IoT). Saya tertarik mengembangkan aplikasi dan sistem berbasis web, mengolah serta menganalisis data, mengeksplorasi model machine learning, text mining, NLP, dan analisis sentimen, serta mempelajari integrasi perangkat, sensor, konektivitas, dan data pada sistem IoT. Selain pengembangan teknologi, saya juga memiliki ketertarikan pada riset dan penelitian, khususnya dalam proses eksplorasi masalah, eksperimen, analisis data, dan pengembangan solusi berbasis teknologi.
